# Advo_Dev Submission

Work lane for Advo_Dev. This repo holds artifacts and evidence. It does not score them.

| Repo | Holds |
| --- | --- |
| [Advo_Dev_Commons](https://github.com/michaelchaves-dev/Advo_Dev_Commons) | Shared commons stub. Protocol not written yet. |
| [Advo_Dev_Submission](https://github.com/michaelchaves-dev/Advo_Dev_Submission) | The submission itself: claim, artifact, evidence, limitations. |
| [Honor_Advo_Stack](https://github.com/michaelchaves-dev/Honor_Advo_Stack) | The plane. Route and write rights. |
| [Honor_Scout_Master](https://github.com/michaelchaves-dev/Honor_Scout_Master) | Scoring constitution. |
| [Honor_Scout_Commons](https://github.com/michaelchaves-dev/Honor_Scout_Commons) | Self-score, ternary vector, reconciled score. |

An Advo_Dev submission does not mark itself verified. Ternary review happens outside this repo. A self-score, if included, is a claim, not a result.

## Layout
